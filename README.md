# 🦋 Butterfly Game

A fun little butterfly game with a **real Monarch butterfly** photo. Fly around a sunny garden, eat flowers, dodge the bees!

## Play it

👉 **https://jawadr-ehman.github.io/butterfly-game/**

Just open the link — no install needed. Works on laptop and phone.

## How to play

- **Keyboard:** Arrow keys or WASD to fly
- **Phone / on-screen:** use the remote buttons
- **Flowers:** Pink +10, Sunflower +20, Purple +30, **Golden +50**
- **Combo:** eat flowers quickly one after another to build a combo up to **x5**
- **Shield:** grab the blue shield — it blocks one bee sting
- **Energy:** flying drains energy; eating flowers refills it
- **Bees:** they chase you! 3 lives, 60 seconds — how high can you score?

## Features

- Real Monarch butterfly photo (not a drawing) with flapping wings
- Sound: flower chime, bee buzz, level-up, background music (mute button)
- Wind gusts, drifting clouds, day garden
- Levels, best score saved in your browser
- Golden flowers, combo multiplier, shield power-up, score popups, confetti

Made with plain HTML + JavaScript. One file, no build step.
